# Viver em Paz para Morrer em Paz — quintinoferreirasilva

Projeto estático em português brasileiro para apresentar o e-book e direcionar o leitor à oferta na Hotmart.

## Conteúdo

- `site/index.html`, `site/style.css` e `site/script.js`: página responsiva, identidade visual e CTA.
- `site/assets/`: capa e banner originais usados pela página.
- `site/favicon.svg`: ícone do site.
- `site/manus-routes.json`: manifesto de rotas.
- `hotmart-copy.md`: título e descrição para cadastro da oferta.
- `assets/source/`: PDF-fonte fornecido para o projeto; fica fora da saída pública `site/`.
- `TODO.md` e `app.config.ts`: registro de entregas e metadados do projeto WebDev.

## Checkout

O CTA está conectado à URL oficial fornecida: `https://pay.hotmart.com/U108118072R`. O endereço fica em `HOTMART_CHECKOUT_URL`, no início de `site/script.js`, e abre em uma nova aba.

## Uso e distribuição

O repositório deve permanecer privado. O PDF-fonte foi incluído como material do projeto e só deve ser distribuído conforme a licença/autorização do responsável. O site publicado está em https://viverpaz-wgkscmsg.manus.space.

A seção de depoimentos contém somente espaços para avaliações reais e autorizadas. O selo “Leitura para refletir” é visual, não uma certificação ou garantia.
